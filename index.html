The Five Python GUI Projects

Each application is cleanly architected with event-driven Tkinter patterns, rigorous input validation, real-time feedback, and persistent storage.

PROJECT 01
Python 3 Tkinter / ttk AST Safe Parsing Math Engine

Smart Calculator with Scientific Engine

A high-precision arithmetic and scientific calculator featuring an AST (Abstract Syntax Tree) safe evaluator, preventing unsafe eval code execution while offering trigonometry, logarithms, power, and real-time history logs.

  • Supports standard arithmetic (+, -, ×, ÷), parentheses, and percentages
  • Scientific functions: √ (sqrt), sin, cos, tan, log10, ln, factorial, π, e
  • Session calculation history with reusable past values and error trapping

PROJECT 02
Python 3 Tkinter Treeview CSV Persistence Currency Engine

Employee Payroll Management System

An enterprise-grade payroll desktop suite that validates employee profiles, computes overtime pay, calculates gross earnings, automated tax withholding, and net salary payouts with CSV export.

  • Complete CRUD: Add, update, delete, and inspect employee salary records
  • Accurate formulas: Basic + Overtime + Allowances - Tax - Other Deductions
  • Local persistence in `payroll_data.csv` with instant export functionality
python3 Python_GUI_Projects/02_Employee_Payroll_System/main.py
PROJECT 03
Python 3 Tkinter / ttk Analytics Engine Grade Criteria

Student Grade Analyzer & Performance Tracker

Analyzes individual and cohort academic performance. Validates 5-subject marks, enforces individual passing standards (minimum 40 in every subject), assigns letter grades, and detects subject strengths.

  • 5-Subject marks validation (0-100) with total score out of 500 & percentage
  • Automatic detection of strongest and weakest subjects for targeted feedback
  • Cohort dashboard with class average, highest, lowest, and CSV reporting
python3 Python_GUI_Projects/03_Student_Grade_Analyzer/main.py

PROJECT 04
Python 3 Tkinter Treeview Stock Alerts CSV Storage

Warehouse Inventory & Stock Tracker

Monitors catalog stock levels, computes cumulative valuation, highlights low-stock and out-of-stock items, and enables instant 4-field search (ID, Name, Category, Supplier).

  • Automatic status calculation: IN STOCK, LOW STOCK, or OUT OF STOCK
  • Real-time search across ID, description, category, and supplier
  • Dynamic dashboard with total catalog count, stock value, and alert counters
python3 Python_GUI_Projects/04_Inventory_Tracker/main.py
PROJECT 05
Python 3 Regular Expressions Logging & Counters Diagnostics GUI

System & Server Log File Analyzer

Parses server, web, and application log files via regular expressions. Segregates events into DEBUG, INFO, WARNING, ERROR, and CRITICAL categories with dedicated error tables and CSV diagnostics export.

  • Robust regex parser with graceful handling of malformed and corrupted lines
  • Severity-based color highlighting with instant error frequency detection
  • Diagnostics summary: error rate %, common error occurrences, and CSV exports
python3 Python_GUI_Projects/05_Log_File_Analyzer/main.py
